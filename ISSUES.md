# ISSUES.md — rbxdserver

Разбор «тупого кода, слабых мест и плохой логики» старого rbxdserver.
Формат: `[серьёзность] файл:строки — проблема → что делать`.

> **Статус после реврайта 2026-09.** Код переписан (архитектура — `AGENTS.md`,
> контракт — `API.md`). Метки: ✅ закрыто реврайтом; 🟡 закрыто частично /
> осознанный компромисс; ❌ открыто. Имена файлов/строк ниже относятся к
> СТАРОМУ коду — сработавшие там решения описаны в AGENTS.md.

## Критично (безопасность)

- ✅ `[CRIT] internal/api/auth.go` — fail-open: пустой токен = весь API без защиты.
  **Решение владельца: auth удалена полностью** (один пользователь, доверенная LAN);
  `--token`/`--token-file` выпилены, `internal/api/auth.go` удалён. Модель доверия
  зафиксирована в `DESIGN.md` — сервис не должен попадать на публичный адрес.
- ✅ `[CRIT] router.go:39-40` — `/places` публичный, `/status` под токеном.
  Токенов больше нет, все эндпойнты равнозначно открыты (следствие решения выше).
- ✅ `[CRIT] handlePlaceFile` — path-traversal (префикс без разделителя + симлинки).
  Теперь: allowlist имён файлов, slug проверяется `filepath.Base`/регэкспом,
  `filepath.EvalSymlinks` + проверка резолва внутри `PlacesDir`.
- ✅ `[HIGH] handleStart` — slug не валидировался, `../../etc` срабатывал.
  Теперь `validSlug` (регэксп + запрет `..`) и `os.Stat(GameConfig.toml)` в
  `StartPlace` **до** занятия портов.
- ❌ `[HIGH] Один плейс на всех + /stop без подтверждения` — по-прежнему один
  активный плейс и любой в LAN может его остановить. Осознанно: пользователь один.
  Пересмотреть, если появятся другие игроки (очередь/аренда плейса).

## Критично (конкурентность)

- ✅ `[CRIT] session.go` — `onEmpty()` под `m.mu` дедлочил всё на до 150 c.
  Теперь решение принимается под локом, вызов — вне его; повторный вход отсекается
  по номеру таймера.
- ✅ `[HIGH] crash_check ABA-гонка` — теперь generation-счётчик: события watcher'ов
  с чужим поколением отбрасываются.
- ✅ `[HIGH] Цикл блокировался в WaitForPort до 150 c` — теперь все ожидания в
  отдельных goroutine, старт рапортует событиями; `/stop` работает всегда;
  незавершённый старт отменяется (`pendingStart.cancel`).
- ✅ `[MED] Гонки state/proc` — переходы только в петле `cmds`; `GetStatus`/`GetLogs`
  читают под `mu`; `go build -race` в интеграционных прогонах чистый.

## Высокий приоритет

- 🟡 `[HIGH] Сессии keyed by username` — для списков больше не важно: список
  игроков теперь из presence rbxd (ключ `id_num`). Username остаётся ключом
  только легаси WS-счётчика `connections`; на присутствие и автостоп не влияет.
- 🟡 `[HIGH] WS «чёрная дыра»` — read deadline 60 c + обработка pong появились,
  лимита коннектов и серверного ping-тика нет. Клиент пока ничего не шлёт —
  deadline закрывает мёртвые сокеты.
- 🟡 `[HIGH] TOCTOU портов` — готовность проверяется HTTP-запросом (`/rfd/status`),
  веб при неудаче бинда ретраится на новом порту (3 попытки). RCC-порт (UDP)
  проверить невозможно в принципе; двух одинаковых портов подряд за сеанс
  не замечено.
- ❌ `[HIGH] --backend wine захардкожен` — RCC по-прежнему всегда wine. Флага
  бэкенда в конфиге демона нет. (В реврайте 2026-09 — не трогалось по просьбе.)
- ✅ `[HIGH] web.go:240 — join-команда с несуществующим `--web_host`` — устарело
  по сути: у `player`-мода rbxd флаги `--web_host/--host/--web_port/--port` есть
  (см. `player.py`). А вот захардкоженные кнопки тест-плейсов заменены на
  динамические из `/places`.
- ❌ `[HIGH] CheckOrigin: true` — WS принимает любой origin. Осталось; при появлении
  врагов в LAN — origin-allowlist.

## Средний приоритет

- ✅ `[MED] stderr не мержился в лог` — теперь один `os.Pipe` на stdout+stderr,
  буфер сканера 1 МБ, хвост без `\n` дочитывается.
- ✅ `[MED] Stop: безусловный SIGKILL через 5 c (PID-reuse)` — теперь SIGTERM →
  ожидание фактического выхода (канал `Exited`) → SIGKILL только если жив.
- ✅ `[MED] Scan() возвращал JSON null` — теперь всегда `[]`.
- ❌ `[MED] Версия плейса перечитывается с диска на каждый /status` — осталось
  (регэксп по TOML, без кэша по mtime). Нагрузка мизерная, но поллится клиентами.
- ✅ `[MED] favorites read-modify-write гонка` — под мьютексом роутера.
- ✅ `[MED] Голый ListenAndServe без таймаутов` — `http.Server` с
  ReadHeader/Read/Idle-таймаутами; WriteTimeout сознательно не ставится
  (рвёт WebSocket).
- ✅ `[MED] log.Fatal при парсинге флагов` — `ParseFlags(argv) (*Config, error)`.
- ✅ `[MED] Нет graceful shutdown` — SIGTERM: `srv.Shutdown` → `sup.Shutdown`
  (сессия без кулдауна) → `cdn.Stop`.
- 🟡 `[MED] Фаервол открывал только API-порт` — теперь API + CDN (обоим можно
  указать опции); сессийные веб/RCC порты эфемерные — документировано, но
  поштучно не открываются.
- ✅ `[MED] --state-dir в module.nix, --token в ps` — флаги удалены из демона и
  модуля; добавлены `--cdn-port`, `--web-cooldown`, `--skins-dir`.
